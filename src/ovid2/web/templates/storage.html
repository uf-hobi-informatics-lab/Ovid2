Storage accounts {% call help.tip_block(label="What is a storage account?") %} A storage account holds the credentials and shared endpoint metadata (host, region, account, bucket, container…) for one reachable system where data lives — a filesystem, an object store (S3, GCS, Azure Blob), or a database / warehouse (Snowflake, Databricks, Postgres, SQL Server). A pipeline picks a storage account for its input and output, then chooses the folder / bucket / schema at run time. {% endcall %}

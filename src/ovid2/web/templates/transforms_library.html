Transform library {% call help.tip_block(label="Transform library") %} Reusable chains you can assign to any pipeline. A transform is a named, reusable chain of library ops — your own user-defined function. Build it with the form or write the YAML, then assign it to tables of any pipeline: it runs in the pipeline's transform stage, between deduplicate and map, on every engine. derive_column computes a column from a Spark-SQL expression (e.g. coalesce(nullif(trim(SEX), ''), 'UN')) checked against an allow-list of row functions. {% endcall %}

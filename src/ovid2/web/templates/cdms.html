Common Data Models

A CDM (Common Data Model) declares the table list, composite dedup keys, identifier columns, and bounded valuesets the generic ETL engine relies on. The pipeline never imports a specific CDM module — it reads state from a CdmHandle registered here. YAML-authored CDMs live under src/ovid2/resources/cdms/ and are regenerated via ovid2 tools import-cdm; pipeline-family CDMs (nursing, veritas, tumor) remain declared in Python.

Workflows {% call help.tip_block(label="What is a workflow?") %} Chain saved pipelines into one automated run. A workflow is a graph of steps; each step is a saved pipeline. A data link feeds the output of one step into the input of the next. An after link only sets the order, so steps can read and write completely different storage. The workflow is started by its trigger (manual, schedule, interval or a watched folder — inherited from the first pipeline). If any step fails the run stops and every finished step is rolled back: new tables are removed and overwritten tables are restored. {% endcall %}

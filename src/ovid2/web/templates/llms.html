The assistant (the LLM button on the right rail) uses two kinds of model. System 1 (e.g. JEV or a similar decision model) is a fast decision model that is asked first. When it abstains, errors, or is not confident enough, the question goes to the general LLM (any OpenAI-compatible endpoint). API keys are stored in secrets.d/ (mode 0600) and are only read by a short-lived executor subprocess. The web server never holds them.

Routing

Read-only tools (jobs, runs, logs, configs, data space) run automatically with a short-lived token limited to the chatting user's permissions (at most pipeline operator). Actions such as submitting or cancelling a job are shown as proposals you must click Run on. No secrets, settings, users or data rows are exposed.

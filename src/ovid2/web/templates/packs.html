Domain packs {% call help.tip_block(label="What is a domain pack?") %} A drop-in bundle that teaches Ovid2 a data domain. A pack can ship a target data model (CDM), data-health checks with severities and remediation hints, report-cycle packages, vocabularies, report templates and — for pip-installed packs only — check operators and fixers. PCORnet CDM v7.0 is the built-in reference pack. Installing a pack does not enable it: an administrator lists it in OVID2_PACKS_ENABLED or runs ovid2 tools pack enable <id>. {% endcall %}

{# Pre-paint appearance (included in of every full page, BEFORE the stylesheet link). The signed-in user's appearance is stored server-side (``web_user_prefs`` via ``/api/v1/me/appearance``) and rendered here as ``window.OVID2_APPEARANCE`` so the very first paint already has the right theme + overrides on any browser / laptop. Nothing is read from browser storage. ``theme.js`` takes over after load (same object) and re-derives the accent hover / subtle / ink shades. ``user_appearance(request)`` returns defaults for anonymous visitors (login page) and machine principals. ``|tojson`` escapes < > & so the value cannot break out of the script element. #}
